## Description

Creating new objects in AD, such as user accounts, groups, organizational units (OUs), or trust relationships. Logged as Event ID 5137. Examples:<br><br>- User Account Creation: New user account.<br>- Group Creation: New security/distribution group.<br>- OU Creation: New organizational unit.<br>- Service Account Creation: New service account for automation or malicious tasks.<br>- Trust Object Creation: Trust relationship with another domain.
