## Description

Requests for authentication credentials via Kerberos or other methods like NTLM and LDAP queries. Examples:<br><br>- Kerberos TGT and Service Tickets (Event IDs 4768, 4769)<br>- NTLM Authentication Events<br>- LDAP Bind Requests.
