## Description

An adversary may compress or encrypt data that is collected prior to exfiltration using 3rd party libraries. Many libraries exist that can archive data, including [[kb/mitre/attack/techniques/T1059.006-python|Python]] rarfile [^3] , libzip [^1] , and zlib [^2] . Most libraries include functionality to encrypt and/or compress data.<br><br>Some archival libraries are preinstalled on systems, such as bzip2 on macOS and Linux, and zip on Windows. Note that the libraries are different from the utilities. The libraries can be linked against when compiling, while the utilities require spawning a subshell, or a similar execution mechanism.
