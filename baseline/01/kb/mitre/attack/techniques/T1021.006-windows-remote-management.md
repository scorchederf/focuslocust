## Description

Adversaries may use [[kb/mitre/attack/techniques/T1078-valid-accounts|Valid Accounts]] to interact with remote systems using Windows Remote Management (WinRM). The adversary may then perform actions as the logged-on user.<br><br>WinRM is the name of both a Windows service and a protocol that allows a user to interact with a remote system (e.g., run an executable, modify the Registry, modify services).[^4]  It may be called with the `winrm` command or by any number of programs such as PowerShell.[^2]  WinRM  can be used as a method of remotely interacting with [[kb/mitre/attack/techniques/T1047-windows-management-instrumentation|Windows Management Instrumentation]].[^3]
