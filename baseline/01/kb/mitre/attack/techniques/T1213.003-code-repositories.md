## Description

Adversaries may leverage code repositories to collect valuable information. Code repositories are tools/services that store source code and automate software builds. They may be hosted internally or privately on third party sites such as Github, GitLab, SourceForge, and BitBucket. Users typically interact with code repositories through a web application or command-line utilities such as git.<br><br>Once adversaries gain access to a victim network or a private code repository, they may collect sensitive information such as proprietary source code or [[kb/mitre/attack/techniques/T1552-unsecured-credentials|Unsecured Credentials]] contained within software's source code.  Having access to software's source code may allow adversaries to develop [[kb/mitre/attack/techniques/T1587.004-exploits|Exploits]], while credentials may provide access to additional resources using [[kb/mitre/attack/techniques/T1078-valid-accounts|Valid Accounts]].[^1] [^2] <br><br>**Note:** This is distinct from [[kb/mitre/attack/techniques/T1593.003-code-repositories|Code Repositories]], which focuses on conducting [[kb/mitre/attack/tactics/TA0043-reconnaissance|Reconnaissance]] via public code repositories.
