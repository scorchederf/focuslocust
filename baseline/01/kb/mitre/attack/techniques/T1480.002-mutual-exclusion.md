## Description

Adversaries may constrain execution or actions based on the presence of a mutex associated with malware. A mutex is a locking mechanism used to synchronize access to a resource. Only one thread or process can acquire a mutex at a given time.[^4] <br><br>While local mutexes only exist within a given process, allowing multiple threads to synchronize access to a resource, system mutexes can be used to synchronize the activities of multiple processes.[^4]  By creating a unique system mutex associated with a particular malware, adversaries can verify whether or not a system has already been compromised.[^2] <br><br>In Linux environments, malware may instead attempt to acquire a lock on a mutex file. If the malware is able to acquire the lock, it continues to execute; if it fails, it exits to avoid creating a second instance of itself.[^1] [^5] <br><br>Mutex names may be hard-coded or dynamically generated using a predictable algorithm.[^3]

| [S0632](https://attack.mitre.org/software/S0632) | GrimAgent | GrimAgent uses the last 64 bytes of the binary to compute a mutex name. If the generated name is invalid, it will default to the generic `mymutex`.[^1]  |

| [S1183](https://attack.mitre.org/software/S1183) | StrelaStealer | StrelaStealer variants include the use of mutex values based on the victim system name to prevent reinfection.[^1]  |
| [S1196](https://attack.mitre.org/software/S1196) | Troll Stealer | Troll Stealer creates a mutex during installation to prevent duplicate execution.[^1]  |
| [S1202](https://attack.mitre.org/software/S1202) | LockBit 3.0 | LockBit 3.0 can create and check for a mutex containing a hash of the `MachineGUID` value at execution to prevent running more than one instance.[^1]  |
| [S1236](https://attack.mitre.org/software/S1236) | CLAIMLOADER | CLAIMLOADER has created hardcoded mutex to ensure only a single instance of the malware is running.[^1] [^2]  |
| [S1239](https://attack.mitre.org/software/S1239) | TONESHELL | TONESHELL has created a mutex to avoid duplicate execution.[^1]  |
| [S1242](https://attack.mitre.org/software/S1242) | Qilin | Qilin can create a mutex to ensure only one instance is running.[^1]  |
| [S1247](https://attack.mitre.org/software/S1247) | Embargo | Embargo has utilized a hardcoded mutex name of “LoadUpOnGunsBringYourFriends” using the `CreateMutexW()` function.[^1]  Embargo has also utilized a hardcoded mutex name of “IntoTheFloodAgainSameOldTrip."[^2]  |
| [S9019](https://attack.mitre.org/software/S9019) | PureCrypter | PureCrypter code contains a global mutex.[^1]  |
| [S9023](https://attack.mitre.org/software/S9023) | HiddenFace | HiddenFace can create a mutex to ensure only one instance is running at a time.[^1] <br> |
