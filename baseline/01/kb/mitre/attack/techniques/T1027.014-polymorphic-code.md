## Description

Adversaries may utilize polymorphic code (also known as metamorphic or mutating code) to evade detection. Polymorphic code is a type of software capable of changing its runtime footprint during code execution.[^1]  With each execution of the software, the code is mutated into a different version of itself that achieves the same purpose or objective as the original. This functionality enables the malware to evade traditional signature-based defenses, such as antivirus and antimalware tools.[^2]  <br>Other obfuscation techniques can be used in conjunction with polymorphic code to accomplish the intended effects, including using mutation engines to conduct actions such as [[kb/mitre/attack/techniques/T1027.002-software-packing|Software Packing]], [[kb/mitre/attack/techniques/T1027.010-command-obfuscation|Command Obfuscation]], or [[kb/mitre/attack/techniques/T1027.013-encrypted-encoded-file|Encrypted/Encoded File]].[^4] [^3] <br>
