## Description

Adversaries may attempt to find unsecured credentials in Group Policy Preferences (GPP). GPP are tools that allow administrators to create domain policies with embedded credentials. These policies allow administrators to set local accounts.[^2] <br><br>These group policies are stored in SYSVOL on a domain controller. This means that any domain user can view the SYSVOL share and decrypt the password (using the AES key that has been made public).[^3] <br><br>The following tools and scripts can be used to gather and decrypt the password file from Group Policy Preference XML files:<br><br>* Metasploit’s post exploitation module: `post/windows/gather/credentials/gpp`<br>* Get-GPPPassword[^1] <br>* gpprefdecrypt.py<br><br>On the SYSVOL share, adversaries may use the following command to enumerate potential GPP XML files: `dir /s * .xml`<br>
