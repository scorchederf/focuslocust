## Description

Adversaries may corrupt or wipe the disk data structures on a hard drive necessary to boot a system; targeting specific critical systems or in large numbers in a network to interrupt availability to system and network resources. <br><br>Adversaries may attempt to render the system unable to boot by overwriting critical data located in structures such as the master boot record (MBR) or partition table.[^7] [^4] [^3] [^5] [^2]  The data contained in disk structures may include the initial executable code for loading an operating system or the location of the file system partitions on disk. If this information is not present, the computer will not be able to load an operating system during the boot process, leaving the computer unavailable. [[kb/mitre/attack/techniques/T1561.002-disk-structure-wipe|Disk Structure Wipe]] may be performed in isolation, or along with [[kb/mitre/attack/techniques/T1561.001-disk-content-wipe|Disk Content Wipe]] if all sectors of a disk are wiped.<br><br>On a network devices, adversaries may reformat the file system using [[kb/mitre/attack/techniques/T1059.008-network-device-cli|Network Device CLI]] commands such as `format`.[^1] <br><br>To maximize impact on the target organization, malware designed for destroying disk structures may have worm-like features to propagate across a network by leveraging other techniques like [[kb/mitre/attack/techniques/T1078-valid-accounts|Valid Accounts]], [[kb/mitre/attack/techniques/T1003-os-credential-dumping|OS Credential Dumping]], and [[kb/mitre/attack/techniques/T1021.002-smb-windows-admin-shares|SMB/Windows Admin Shares]].[^7] [^4] [^3] [^5] 

## Procedure Examples
| ID | Name | Use |
| --- | --- | --- |
| [S0140](https://attack.mitre.org/software/S0140) | Shamoon | Shamoon has been seen overwriting features of disk structure such as the MBR.[^4] [^3] [^2] [^1]  |
| [[kb/mitre/attack/software/S0364-rawdisk\|S0364]] | RawDisk | [[kb/mitre/attack/software/S0364-rawdisk\|RawDisk]] was used in Shamoon to help overwrite components of disk structure like the MBR and disk partitions.[^1] [^2]  |
| [S0380](https://attack.mitre.org/software/S0380) | StoneDrill | StoneDrill can wipe the master boot record of an infected computer.[^1]  |
| [S0607](https://attack.mitre.org/software/S0607) | KillDisk | KillDisk overwrites the first sector of the Master Boot Record with “0x00”.[^1]  |
| [S0689](https://attack.mitre.org/software/S0689) | WhisperGate | WhisperGate can overwrite the Master Book Record (MBR) on victim systems with a malicious 16-bit bootloader.[^5] [^2] [^3] [^4] [^1] [^6]  |
| [S0693](https://attack.mitre.org/software/S0693) | CaddyWiper | CaddyWiper has the ability to destroy information about a physical drive's partitions including the MBR, GPT, and partition entries.[^1] [^2]  |
| [S0697](https://attack.mitre.org/software/S0697) | HermeticWiper | HermeticWiper has the ability to corrupt disk partitions, damage the Master Boot Record (MBR), and overwrite the Master File Table (MFT) of all available physical drives.[^1] [^2] [^3] [^4]  |
| [S1134](https://attack.mitre.org/software/S1134) | DEADWOOD | DEADWOOD opens and writes zeroes to the first 512 bytes of each drive, deleting the MBR. DEADWOOD then sends the control code `IOCTL_DISK_DELETE_DRIVE_LAYOUT` to ensure the MBR is removed from the drive.[^1]  |
| [S1135](https://attack.mitre.org/software/S1135) | MultiLayer Wiper | MultiLayer Wiper opens a handle to `\\\\\\\\.\\\\PhysicalDrive0` and wipes the first 512 bytes of data from this location, removing the boot sector.[^1]  |
| [S1136](https://attack.mitre.org/software/S1136) | BFG Agonizer | BFG Agonizer retrieves a device handle to `\\\\.\\PhysicalDrive0` to wipe the boot sector of a given disk.[^1]  |
| [S1151](https://attack.mitre.org/software/S1151) | ZeroCleare | ZeroCleare can corrupt the file system and wipe the system drive on targeted hosts.[^2] [^1] [^3]  |
| [S1178](https://attack.mitre.org/software/S1178) | ShrinkLocker | ShrinkLocker has used [[kb/mitre/attack/software/S9002-diskpart\|Diskpart]] to format newly-created partitions.[^1]   |
| [[kb/mitre/attack/software/S9002-diskpart\|S9002]] | Diskpart | [[kb/mitre/attack/software/S9002-diskpart\|Diskpart]] can be used to delete a partition or a volume.[^1]  [[kb/mitre/attack/software/S9002-diskpart\|Diskpart]] can also be used to remove all partitions or volume formatting from the selected disk.[^2]     |
