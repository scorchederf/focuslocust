## Description

Adversaries may abuse CMSTP to proxy execution of malicious code. The Microsoft Connection Manager Profile Installer (CMSTP.exe) is a command-line program used to install Connection Manager service profiles. [^2]  CMSTP.exe accepts an installation information file (INF) as a parameter and installs a service profile leveraged for remote access connections.<br><br>Adversaries may supply CMSTP.exe with INF files infected with malicious commands. [^1]  Similar to [[kb/mitre/attack/techniques/T1218.010-regsvr32|Regsvr32]] / ”Squiblydoo”, CMSTP.exe may be abused to load and execute DLLs [^3]   and/or COM scriptlets (SCT) from remote servers. [^6]  [^4]  [^5]  This execution may also bypass AppLocker and other application control defenses since CMSTP.exe is a legitimate binary that may be signed by Microsoft.<br><br>CMSTP.exe can also be abused to [[kb/mitre/attack/techniques/T1548.002-bypass-user-account-control|Bypass User Account Control]] and execute arbitrary commands from a malicious INF through an auto-elevated COM interface. [^3]  [^4]  [^5]
